# 暴虎冯河 · C++ 控制台文字 Demo 设计

日期：2026-09-19  
状态：待用户确认规格后进入实现计划

## 目标

用 **C++ 控制台（黑框）文字版** 验证一套核心玩法：蓄力冲刺打虎换距离，力越大击退越远，反冲也越大，可能掉进河里。

范围：**只做第一关限时生存**。不做另外两关、不做图形界面。

## 主题映射（玩法，不强调寓意）

| 元素 | 在 Demo 中的角色 |
|------|------------------|
| 虎 | 左侧威胁，持续靠近；贴身则失败 |
| 人 | 玩家，只能靠冲刺/反冲改变位置 |
| 河 | 右侧失败边界；反冲过头则落水失败 |

布局（一维侧视）：`虎 —— 人 —— 河`

## 核心循环

1. 虎持续向人靠近。
2. 玩家蓄力，松手后朝虎冲刺。
3. 若冲刺命中虎：按「力」结算虎的击退与人的反冲（反冲方向朝河）。
4. 若虎进入贴身距离 → 失败（贴身死）。
5. 若人位置越过河界 → 失败（落水死）。
6. 若倒计时归零且人仍存活 → 胜利。

## 操作

推荐实现（Windows 控制台）：

- **按住空格**：蓄力（蓄力条 0→1）
- **松开空格**：释放冲刺（力 = 当前蓄力比例）

备选（若按住检测不稳）：按一次空格开始蓄力，再按一次释放；用两次按键间隔映射蓄力（封顶）。

无左右移动键：位置只由冲刺与反冲改变。

## 显示

每帧（或固定 tick）刷新一行示意，例如：

```text
时间: 12.4s  蓄力: [####------] 40%
[虎]........[人]....[~河~]
```

- 用字符间距近似一维坐标
- 结束时打印原因：`存活` / `贴身死` / `落水死`

## 数值初值（可调常量）

| 项 | 初值 | 说明 |
|----|------|------|
| 生存时间 | 30 秒 | 倒计时 |
| 蓄力满时长 | 1.2 秒 | 连续按住至满 |
| 世界坐标 | 一维：`x` 增大朝向河。河界 `riverX = 20`；人初始 `playerX = 12`；虎初始 `tigerX = 0`；贴身距离约 `1.0` | 显示时把 x 映射到一行字符 |
| 虎接近速度 | 匀速、偏慢 | 给人蓄力反应时间 |
| 贴身致死距离 | 较小阈值 | 虎与人距离 ≤ 该值则死 |
| 冲刺最大位移 | 与满蓄力对应 | `位移 = 力 × 冲刺系数` |
| 击退距离 | `力 × 击退系数` | 满蓄力应明显推开虎 |
| 反冲距离 | `力 × 反冲系数` | 满蓄力反冲约为「站位到河边」的 80%～100% |
| 未命中虎 | 冲到最远点停下 | 无反冲（或极小后摇，demo 可无） |

调参目标：

- **轻蓄力**：小幅推虎，几乎不掉河 → 安全但空间紧张
- **满蓄力**：大换空间，几乎赌落水 → 高风险高收益

## 结算规则（命中时）

设蓄力比例 `p ∈ [0, 1]`：

1. 人沿朝虎方向移动 `p × dashRange`（冲刺过程可用瞬时位移简化）。
2. 若冲刺后与虎距离仍大于碰撞半径 → 未命中，人停在冲刺终点。
3. 若命中：
   - 虎沿远离人方向移动 `p × knockbackRange`
   - 人沿朝河方向移动 `p × recoilRange`
4. 移动后立刻检查贴身与落水。

简化约定（降低实现复杂度）：

- 冲刺与击退/反冲可在**同一 tick 内瞬时结算**，不做多帧动画。
- 蓄力期间人不能再次冲刺；冲刺结算完成前忽略新的蓄力（或结算后立即允许）。

## 技术形态

- 语言：C++（建议 C++17）
- 平台：Windows 控制台
- 输入：`<conio.h>` 的 `_kbhit` / `_getch`，或 Win32 控制台 API
- 循环：固定 timestep（如 50ms）或测量 `deltaTime`
- 单文件或 `main.cpp` + 少量头文件即可；无第三方依赖

构建示例（MSVC）：

```text
cl /EHsc /std:c++17 main.cpp
```

或 MinGW：

```text
g++ -std=c++17 -O2 -o baohu main.cpp
```

## 验收标准

1. 能编译运行，黑框内可见虎/人/河相对位置、蓄力条、倒计时。
2. 蓄力越长，命中后虎退得越远、人反冲越远；满蓄力存在明显落水风险。
3. 虎贴身或人落水会失败并提示原因；撑满时间会胜利。
4. 无需图形库，仅控制台文字。
