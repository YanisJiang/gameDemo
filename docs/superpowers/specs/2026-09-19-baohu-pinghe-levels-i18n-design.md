# 暴虎冯河 · 三关参数链 + 多语言结局 设计

日期：2026-09-19  
状态：待用户确认规格后进入实现计划  
前置：`games/baohu-pinghe/` 控制台 demo（单关限时生存）已可玩

## 目标

在**不改核心操作**的前提下：

1. 做成 **3 关参数关卡链**（同手感、不同约束）
2. 加入 **结束/过关文案**，并支持 **中英多语言**（字符串表，逻辑不写死文案）

暂不做：体力系统（B）、得分挑战（C）、安卓。

## 核心操作（不变）

- 空格按住蓄力，松开朝虎冲刺
- 人自动向河漂；蓄力时人减速漂、虎加速；冲刺动画期间虎略减速
- 危区贴身死；进河落水死
- 反冲：约 75% 蓄力 = 1× 基准反冲，100% 更大反冲

## 流程

```text
启动 → 选语言(1 中文 / 2 English，默认中文)
     → 关卡 1 → (通关) → 关卡 2 → (通关) → 关卡 3 → 全通文案
                ↘ 失败：本关结局文案；R 重开本关；Q 退出
```

- 每关限时：**12 秒**（三关合计约等于原单关体感）
- 过关条件：该关倒计时归零且未死
- 失败：贴身死 / 落水死 → 显示对应文案，停留在结束态
- 全通：三关均过 → 显示通关文案；R 从第 1 关重开整局；Q 退出

语言：仅在启动时选择一次（本版不做局内按 L 切换；预留扩展）。

## 三关参数（示意初值，实现时可微调）

以当前 `GameConfig::defaults()` 为「基准难度」，三关为相对偏移：

| 关 | id | 关题 key | 相对基准的主要变化 |
|----|-----|----------|-------------------|
| 1 | `trial` | `level.1.title` | 略易：虎速 ×0.9，河界略远或站位略宽 |
| 2 | `rising` | `level.2.title` | **逼岸**：`riverX` 明显更小（河更近），河面显示格数可略增 |
| 3 | `berserk` | `level.3.title` | **狂虎**：虎速 ×1.15；命中后额外「岸滑」反冲（见下） |

### 岸滑（仅第 3 关）

命中结算反冲后，再附加：

`extraSlide = k * recoilJustApplied`（建议 `k ≈ 0.15`）

仅第 3 关 `bankSlipFactor > 0`；第 1/2 关为 0。

### 关卡配置结构（建议）

```text
struct LevelConfig {
  const char* id;
  const char* titleKey;   // i18n
  double surviveSec;      // 12
  GameConfig game;        // 完整数值（或相对 defaults 的补丁在加载时合并）
  double bankSlipFactor;  // 0 或 0.15
};
```

三关表静态常量即可。

## 多语言

### 原则

- 所有玩家可见文案走 **key → 字符串**
- 支持 locale：`zh`、`en`
- 缺 key 时回退到 `zh` 或 key 本身（二选一，实现定：**回退 zh，再不行显示 key**）

### 建议 key 列表

| key | 用途 |
|-----|------|
| `lang.prompt` | 启动选语言提示 |
| `level.1.title` / `level.2.title` / `level.3.title` | 关题 |
| `hud.hint` | 操作提示（空格蓄力…） |
| `end.melee` | 贴身死 |
| `end.river` | 落水死 |
| `end.level_clear` | 本关通过 |
| `end.all_clear` | 三关通关 |
| `end.retry` | R 重开 / Q 退出 说明 |

中英文案由实现时写入（语气贴合「暴虎冯河」：莽撞/分寸），不必在本规格锁死逐字译文，但 **key 集合固定**。

### 代码组织建议

- `games/baohu-pinghe/i18n.hpp` + `i18n.cpp`：`setLocale` / `tr(key)`
- 或单文件内 `static` 表；优先独立文件便于加语言

## UI 调整（控制台）

在现有居中 HUD 上增加：

- 当前关卡：`1/3` + 翻译后的关题
- 结束态：结局文案用 `tr(...)`，不再写死中文
- 启动态：语言选择占一屏，选完再进关卡 1

战场三行路/河/危区逻辑保持现有实现。

## 验收标准

1. 启动可选中/英，之后 HUD 与结局文案随语言变化  
2. 三关可连续推进；每关 12s；失败可 R 重开**本关**  
3. 第 2 关明显更「靠河」；第 3 关虎更快且满蓄更易被岸滑送进河  
4. 操作键位与核心循环与现版一致  
5. `/MT` 仍能打出可分发的 `baohu.exe`
